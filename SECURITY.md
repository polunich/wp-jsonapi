# security policy

## supported versions

security fixes are released for the latest minor version of the latest major version.
older minor versions do not receive fixes; upgrade to the latest release of the current
major version before reporting.

## reporting a vulnerability

use the "Report a vulnerability" button on the Advisories page of the repository, which
opens a private report through GitHub private vulnerability reporting.

please do not report security vulnerabilities through public issues, discussions or pull
requests.
